# Phase 8: 学習用 SLI/SLO

小規模な学習用の指標です。**まだ測定していないため、達成済みとは言えません。** 目標値は、仮の出発点です。故障実験を含む観察の後に、この定義で本当に利用者の体験を表せるかを見直します。

## 測るもの

測定は、Prometheus が API Pod の `/metrics` から集める次の 2 つの系列だけで行います。

- `workboard_http_requests_total{method, route, status}`
- `workboard_http_request_duration_seconds{method, route}`（ヒストグラム）

### SLI 1: 成功率

- **定義:** 対象のリクエストのうち、5xx 以外のステータスで応答できた割合。
- **分子:** `status` が 5xx ではないリクエスト数。
- **分母:** 対象のリクエスト数（除外条件を除く）。
- **PromQL（直近 5 分の割合）:**

```text
1 - (
  sum(rate(workboard_http_requests_total{route!~"/health/.*",status=~"5.."}[5m]))
  /
  sum(rate(workboard_http_requests_total{route!~"/health/.*"}[5m]))
)
```

### SLI 2: 応答時間（p95）

- **定義:** 対象のリクエストの処理時間の 95 パーセンタイル。
- **対象:** SLI 1 と同じ。
- **PromQL（直近 5 分）:**

```text
histogram_quantile(0.95, sum by (le) (rate(workboard_http_request_duration_seconds_bucket{route!~"/health/.*"}[5m])))
```

## 目標（SLO）の案

| SLI | 目標 | 期間 |
| --- | --- | --- |
| 成功率 | 99% 以上 | 直近 28 日の移動窓 |
| p95 応答時間 | 500 ms 未満（ヒストグラムのバケット境界で 0.5 秒以下） | 直近 28 日の移動窓 |

- 期間は、日・週の変動をならせて、かつ長すぎない値として 28 日を仮置きした。学習環境は常時動かさないため、実際には 28 日分の連続した測定はできない。
- 99% は、1 か月でおよそ 7 時間の失敗を許す水準。DB が単一 Pod であることを踏まえた仮の値で、根拠の測定はまだない。
- 応答時間の目標 500 ms は、WorkBoard のタスク一覧が主な利用であることを踏まえた仮の値。

## 除外条件と注意

- **除外するもの:** `/health/live`・`/health/ready`（kubelet が呼ぶ）、`/metrics`（そもそも計測されない）。
- **4xx は分母に含め、失敗にしない。** 利用者の入力の誤り（存在しない ID など）は API の失敗ではないため。ただし、4xx が急に増えた場合は別の問題（クライアントの誤り、ルーティングの不具合）の兆候なので、別に観察する。
- **この SLI が見えないもの:** Web（Nginx）が返した 502/504、API に届く前に失敗した要求、port-forward や Ingress / ALB の失敗。利用者が見たエラーより少なく見える。実験 C・D で、メトリクスとクライアントの観測の差を確認する。
- **ヒストグラムの粒度:** `histogram_quantile` は、バケットの境界の間を線形補間した推定値で、既定のバケットでは 0.5 秒と 1 秒の間に粗さがある。
- **母数が少ないとき:** 学習環境ではリクエストが少なく、少数の失敗で割合が大きく動く。リクエスト数も併せて見る。
- **新しく現れる系列:** あるステータスが初めて現れたとき、`increase` や `rate` はその最初の 1 件を数えないことがある。
- **許容できる失敗の予算（エラーバジェット）:** 28 日で成功率 99% なら、失敗してよいのは全リクエストの 1%。使い切ったときの対応（新機能の停止など）は、学習では定めない。

## 見直しの観点

- 測定前に目標を断言しない。測ってから、実績と照らして目標を直す。
- 目標を達成していても、利用者が不便なら SLI の定義が悪い。逆の場合も同じ。
- 2 つの SLI で十分か、可用性（Pod が動いていること）や再起動を別に見る必要があるか。
